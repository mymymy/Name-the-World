Name the World

Suggestions

Offer a list of matching names as you type, to pick from. Turn it off to type every answer out in full, which is harder.

Moving on

What happens once you have named a place. On tap waits for you to choose where to go next; Automatic moves straight on to the nearest place still unnamed.

Marking

When answers are marked right or wrong. At the end holds everything back until you tap Check answers, so nothing gives the game away; As you go marks each answer the moment you give it.

Motion

Gliding between places, confetti and the other movement. Turn it off for a map that changes without animating. It starts off if your device asks for reduced motion.

Start again

Forget every answer in every game and begin from an empty map. This cannot be undone.
